Terms of Reference (ToR)

Social Media API Integration (Posting and Data Storage)

1. Background

The NGO Forum on Cambodia manages official social media platforms including Facebook, Instagram, YouTube, LinkedIn, Website, and TikTok to support advocacy, public awareness, and civic engagement. To improve operational efficiency, the organization integrates these platforms into an internal social media management system using approved APIs.

2. Purpose

This Terms of Reference (ToR) defines the scope, objectives, roles, and governance framework for using social media APIs, including TikTok APIs, for content posting and limited data storage.

3. Scope of Work

The API integration will be used for:

  • Posting approved content (posts and videos) to official NGO social media accounts
  • Storing limited post-related data for internal record-keeping
  • Coordinating content publishing across multiple platforms

Out of scope:

  • Collection of personal user data
  • Commercial use of data
  • Selling or sharing data with third parties

4. Data Storage Scope

Only non-personal and non-sensitive data may be stored, including:

  • Post captions and media metadata
  • Post IDs, timestamps, and platform names
  • Posting status (published, scheduled, failed)

No personal user data, private messages, comments, or sensitive information shall be collected or stored.

5. Roles and Responsibilities

Management

  • Approve API usage and internal policies
  • Ensure organizational compliance

Communications Team

  • Prepare, review, and approve content
  • Ensure content accuracy and alignment with NGO values

IT / Technical Team

  • Implement secure API integrations
  • Manage data storage security
  • Restrict system access to authorized users only

6. Compliance and Ethics

All API usage must comply with applicable platform developer terms, community guidelines, data protection principles, and relevant laws.

7. Duration and Review

This ToR is effective upon approval and shall be reviewed annually or when platform policies or organizational requirements change.
