About NGOF Media Manager

A centralized workspace designed for official organizational communication and social media publishing.

Authorized use: NGOF Media Manager is intended for authorized personnel and official organizational social media accounts. A user must authenticate and grant permission before the application can use a supported social media integration on that user's behalf.

What the platform provides

The platform supports a controlled workflow from preparing content to publishing through supported social media APIs.

01

Content Management

Prepare captions and media files for official organizational communications before publication.

02

Account Connections

Connect authorized social media accounts through the authentication and permission flow provided by each platform.

03

Publishing Workflow

Submit approved content to supported social platforms using their available official APIs.

TikTok integration

NGOF Media Manager uses TikTok for Developers products to support authorized TikTok account connections and content publishing workflows.

1

Connect TikTok

An authorized user chooses TikTok inside NGOF Media Manager and is redirected to TikTok's authorization page.

2

Authorize access

The user signs in to TikTok and explicitly grants the permissions requested by the application.

3

Return securely

TikTok returns an authorization response to the registered application callback, where the backend completes the authorization process.

4

Publish selected content

The authorized user can use the available Content Posting API workflow for media selected in the application.
