NGOF Media Manager

NGOF Media Manager is a web platform developed for The NGO Forum on Cambodia. It helps authorized staff manage and publish official media content to social platforms including TikTok, YouTube, Facebook, Instagram, and LinkedIn.

Login with TikTok

Users must authenticate with their TikTok account before publishing content.

How It Works

  1. User clicks "Login with TikTok"
  2. User authorizes NGOF Media Manager
  3. User is redirected back to this website
  4. User uploads and publishes video using TikTok Content Posting API
